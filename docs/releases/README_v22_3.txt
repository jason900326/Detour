DETOUR v0.22.3 — HOME SCREEN RETHINK

這版只重做首頁，不改流程邏輯。

問題：
- 原本首頁比較像一張海報
- CTA 雖然有，但不夠像「可點的下一步」
- 使用者要做的事不夠明確

這版改法：
1. 首頁文案改成更直接
   - 不用先想去哪。先選你現在有幾分鐘。
   - 把空檔交給 DETOUR。

2. CTA 改成 2x2 的時間卡片
   - 15 / 30 / 60 / 90+
   - 每張都是清楚可點的卡片
   - 內含簡短語氣與用途說明
   - 比原本一排數字更像真正入口

3. 增加一個「選一個空檔」區塊
   - 明確告訴使用者：現在就是要選時間
   - 補一句「點了就直接下一步」

4. Hero 區收緊
   - 減少無意義留白
   - 讓首頁從「空」變成「有節奏、有目的」

5. Passport / Settings 保持右上角
   - 沿用上一版覺得對的方向

設計原則：
首頁不是展示品牌氣氛而已，
而是要讓人一打開就知道：
「我現在只要選一個空檔，剩下它幫我處理。」

不需要新增 npm 套件。
