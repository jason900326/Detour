# Detour V2 Playtest Build

> 狀態：ACTIVE / Playtest Build
> 日期：2026-09-21

這份文件是新版 Detour 的完整產品規格。它覆蓋舊版的時間選擇、Mood、預先目的地、Side Event、經濟系統與雙人流程。

## 驗證問題

這一版唯一要回答：

> 完整 10–15 分鐘的新版 Detour，從按下開始到最後抵達，整體到底好不好玩？

舊版 Playtest 的問題是：不知道終點、不知道還要走多久、反覆被要求再走 50 公尺、沒有事件時路段很空，最後像「故意不告訴你目的地的導航」。因此 V2 是 Journey 結構重做，不是 UI facelift。

## 產品方向

主要開啟情境排序為：

1. **C：我現在有一點時間，不知道要幹嘛。**
2. **A：不知道這次會找什麼、走去哪裡。**
3. **B：以前的票、Emoji、照片慢慢累積。**

任何金幣、票券數量、每日任務或其他門檻都不能阻礙「現在直接開始」。

Detour 的價值是帶玩家走一段平常不會走的路，並一路注意平常不會注意的東西。它不是景點推薦、一般導航、任務 RPG、運動或攝影 App。

## 主要規格

### 首頁

首頁只顯示「去繞一下」、可搭配「不知道要幹嘛？」與「約 10 分鐘」。不選時間、Mood、顏色、單／雙人或玩法。出票／撕票只可以是開始後的品牌儀式。

### 短步 Routing

每次只規劃接下來約 1–3 分鐘：不立即 U-turn、避免重走、只在真正轉彎或方向決策時提示。探索目標存在時，玩家注意力在真實世界，不在地圖。

### 偏離

偏離是正常玩法。接受目前 GPS，從目前位置作新的 routing 起點，保留已走路段，逐漸往原本大致探索區域／適合收尾區域拉回，不要求原路返回。

### 探索紙條

每次一個當前探索目標，顯示系統 Emoji 與簡短客觀文字。保留「找到」與永遠可用的「換一個」。目標題庫含具體物件、特徵與城市細節三類；Easy → Medium → Medium / Hard，第一題簡單、Hard 不連續、低命中後自動降難度。

### 找到了

短震動；對應 Emoji 留在本次 Ticket；紙條結束；從目前位置形成下一短段；顯示新目標。不做分數、獎勵、複雜完成動畫或 AI 驗證。

### Ticket

只記錄已發生的 Emoji，不預告未來內容，不顯示問號。Ticket 是單次 Journey 的紀錄、完成回饋、獨特性與未來分享內容。

### 拍照

相機常駐 Journey。找到不等於拍照；玩家想留畫面時可以自由拍攝。MVP 完全不做 AI 圖像辨識。

### Journey 長度

通常 3–4 個主要發現。約 8–10 分鐘開始收尾，最晚約 15 分鐘結束。找到 3–4 個不代表立即結束，也不在剩餘時間無限制塞題。

### Exploration / Closing / Forced Finish

- Exploration：前段給目標、找東西、逐短段生成路線、接受偏離。
- Closing：有約 3 個發現且接近 8–10 分鐘時啟動；停止向外擴張，尋找安全自然的停留點，最多再給一個輕量目標。
- Forced Finish：接近 15 分鐘停止新目標，完成目前 Journey；15 分鐘不是 Failure。

### 收尾位置與 UI

候選優先小公園、廣場、綠地、河岸入口、步行空間、有座位的公共區域。途中只說「差不多了，再往這邊走一小段」，抵達後才揭曉名稱。不要顯示目的地名稱與距離，避免重新變成導航 App。

## 工程範圍

這次先使用系統 Emoji、Typography、基本 View、圓角、線條、照片、GPS polyline、既有 Ticket language、Haptic 與簡單 opacity / scale。不要因 illustrator、粒子、複雜 transition、自製 icon 或每題插畫卡住 Playtest。

OSM／Overpass 只做環境的弱加權，不能證明某個物件存在。現有真實步行 routing、GPS trace、相機與本機 Passport 可重用；不要把舊版 Mood、時間選擇、預先完整目的地與 Side Event 重新接回 V2 首頁。

## 本版不做

Coin、XP、商店、票券貨幣、遊玩次數限制、Daily reward、Streak、Ranking、付費機制、登入、社群、雙人專屬玩法、AI 圖像辨識、複雜收藏與高完成度分享美術。

Monetization hypothesis unresolved。先確認玩家會不會第二次打開、無聊時會不會想到 Detour，以及核心 Journey 是否本身有趣。

## Playtest 觀察表

1. 有沒有真的開始抬頭找東西。
2. 找東西是否比單純導航有趣。
3. 找到了 → Emoji → 下一段是否有完成感。
4. 題目是否蠢、太容易或找不到。
5. 是否仍焦慮到底要去哪、還要多久。
6. 偏離時動態 route 是否自然。
7. Closing 是否讓旅程有結尾。
8. 完成後第一句話。
9. 如果下次又有 10 分鐘沒事，會不會自己再開。
