DETOUR v0.8 — PLACE → MISSION

這版主要不是「多找景點」，而是把 Engine 的判斷單位改成：

    舞台 + 任務

改動重點：
1. 公園不再自動是好推薦；park 基礎分數已大幅降低。
2. 每個候選點都會先生成一個與場景、Mood 有關的任務。
3. Mission playability 會進入候選點評分。
4. 同一趟永遠不會選 3 個 park；green family 最多 1 個。
5. 搜尋候選擴充到圖書館、社區空間、街頭書櫃、信仰節點、徒步街段等。
6. ENGINE LAB 現在直接顯示 Stage + Mission，而不是只列地點。
7. 候選點增加「我知道這裡 / 我來過」回饋。
8. 熟悉地點會永久存在手機本機，之後重新掃描會大幅降權。
9. 標記熟悉後 Engine 會立即從已取得的候選池重新挑 3 個，不需要重新打 API。
10. Journey 會先透露這一站的任務標題，但繼續隱藏地點名稱；抵達後解鎖完整任務。

安裝：
把這個 ZIP 解壓縮到 C:\Users\jason\detour 並允許覆蓋 src。
本版不需要新增 npm 套件。

建議測試：
- 開啟 INDOOR TEST。
- 60 MIN → CAMERA 或 WEIRD。
- 看 ENGINE LAB 是否還是選出 3 個公園。
- 若看到你熟悉的地方，按「我知道這裡 / 我來過」。
- 觀察 SELECTED 是否立即換成別的候選。
- 看三個被選中的任務，問自己：即使我知道那個地方，這個任務有沒有讓我想用不同方式去一次？

這一版仍然不是實地導航：
尚未驗證實際步行路線、入口、封路、營業時間，因此實地模式仍鎖住。
