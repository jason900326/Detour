# Detour — Mood V2 產品決策

> 狀態：ACTIVE / 新決策
> 日期：2026-09-17
> 優先級：本文件在 Mood 定義上覆蓋 `PRODUCT_FOUNDATION.md` 的舊版設計。

## 核心原則

Mood 不為了版面湊固定數量。每一個 Mood 都必須代表不同的使用理由或玩法，而不是只換一組 POI 權重。

目前正式只保留三個 Mood：

| Mood | 使用者意圖 | 核心玩法 |
| --- | --- | --- |
| **隨便走** | 我沒地方要去，帶我亂晃 | 產生一段原本不會發生的路；偏好陌生、帶一點莫名其妙感的 Scene 與城市發現 |
| **吃東西** | 我想出去晃，順便弄點東西吃 | 保留 Detour 路線與尋找體驗，最後抵達低承諾食物／飲料目的地；不是附近美食推薦 App |
| **色色的** | 我想用一個規則重新看城市 | Color Walk；系統抽一個顏色，整趟只追同一個顏色，不使用一般尋找任務 |

## Destination Pool

| Mood | Destination Pool |
| --- | --- |
| **隨便走** | Detour Scene Pool |
| **色色的** | Detour Scene Pool（與隨便走相同） |
| **吃東西** | Food Pool |

「色色的」與「隨便走」的差別發生在沿途玩法，不在終點資料池；Food 不混入 Color Walk 的目的地池。

## 「隨便走」重新定義

原本「這是哪」的精神併入「隨便走」。它不追求最熱門、最知名或最像景點的目的地，而優先追求：

1. 使用者平常不會走的路。
2. 陌生街段與有趣轉折。
3. 城市裡帶一點莫名其妙感的發現。
4. 安全、公開、可步行且符合時間預算。
5. 終點本身可以很小，但最好讓人產生「原來這裡有這個？」的反應。

產品判準：

**隨便走不追求「最值得去的地方」，而追求「一段原本不會發生的路」。**

## 版面

Mood 選擇頁採三卡層級：

1. 「隨便走」為全寬主卡，代表 Detour 的核心體驗。
2. 「吃東西」與「色色的」為下方兩張等寬副卡。
3. 不保留空白第四格，也不為了版面補一個意義不足的 Mood。

## 已移除

- **想安靜**：比較適合作為路線偏好，不足以構成獨立玩法。
- **這是哪**：精神併入「隨便走」。
- **命運／驚喜**：不再保留。
- **怪怪的**：其 oddity 偏好併入「隨便走」。
- **慢慢走**：固定目的地加刻意繞路會放大「明明可以直走」的挫折；目的地輸入與獨立延長路線引擎一併移除。
- **繞一圈**：暫不作為 Mood；若未來驗證有價值，應以 Route Mode 或獨立入口實驗。
