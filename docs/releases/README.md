# Detour release notes archive

這個資料夾收納早期以 `README_vXX.txt` 命名的版本說明與交付紀錄。

## 文件規則

- Repository 根目錄只保留一份正式入口：[`README.md`](../../README.md)
- 產品決策基準：[`PRODUCT_FOUNDATION.md`](../../PRODUCT_FOUNDATION.md)
- 這裡的檔案是歷史快照，不代表目前功能或架構仍維持當時狀態
- 原始檔名保留，方便從 commit / issue / 對話追溯對應版本

新的產品或開發狀態請更新正式文件，不再新增新的 `README_vXX.txt` 到根目錄。
